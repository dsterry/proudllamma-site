# Proud Llama Games

Static website for Proud Llama Games and Project: Kept.

Open `docs/index.html` directly to preview the site locally. No build step or local server is required.

In the repository's GitHub Pages settings, select `main` and `/docs` under **Deploy from a branch**. The site will be available at `https://proudllama.com/`. Put public pages and the files they need in `docs/`. For the source and usage notes for the social icons, see [Social icons](SOCIAL_ASSETS.md).

Keep editable artwork and private generation files in Redoubt or in the ignored `private/` directory in your local checkout. Copy finished web exports into `docs/assets/`. Files committed and pushed to this public repository are visible on GitHub even when they are outside `docs/`.
